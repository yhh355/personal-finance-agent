# Demo Video Submission

Record a 5 to 8 minute video that shows both your face and the application screen.

Use `data/demo_statement.xlsx` rather than a real payment statement. Demonstrate the following sequence:

1. Upload and extract the XLSX file.
2. Set the September 2026 budget limit, saving target, and protected categories.
3. Run the initial analysis.
4. Ask one multi-step question that requires spending insights, transaction evidence, and a saving plan.
5. Expand the Agent tool-call trace and explain the action-observation loop.
6. State the project limitations: manual upload, editable but imperfect categories, no bank integration, and no investment advice.

Before submission, confirm that the recording does not show `.env`, API keys, or personal transaction data. Check the course platform or instructor guidance for the required video upload location and size limit.
